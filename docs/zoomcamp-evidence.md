# Zoomcamp project evidence audit

This is a claim-by-claim audit against the [official final-project brief](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/blob/main/project/README.md). It links completed, inspectable evidence and labels unfinished work. RunGuard is a **local-only** project: the normal site is currently stopped, there is no public URL, and public deployment/CD are deferred in [issue #34](https://github.com/AutoDotAI/RunGuard/issues/34). A passing test in a disposable environment is evidence for that test, not proof that the owner's existing data has been imported or that a public service works.

## Reviewer path and remaining external work

After [#60](https://github.com/AutoDotAI/RunGuard/issues/60) and [#61](https://github.com/AutoDotAI/RunGuard/issues/61) merge, follow the [README command index](../README.md) and [local reviewer guide](reviewer-guide.md) to install, test, start, inspect, and stop the local application. Use the [QA evidence index](reviewer-evidence.md) for exact commands and results. The normal site was stopped at the owner's request; this audit does not start it. The existing SQLite volume remains the recovery source until a verified one-time import is performed.

No screenshot is committed or counted as evidence. A reviewer may capture a redacted local screen after deliberately starting the application; a screenshot must not contain credentials, personal page text, or tokens. [Issue #63](https://github.com/AutoDotAI/RunGuard/issues/63) remains an **owner action**: the owner must evaluate three *other participants' projects* through the course platform. Agent QA on RunGuard and reviews received on RunGuard do not satisfy that requirement.
